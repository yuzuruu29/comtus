A Refined Lamp recommended · evolution
Keeps today's soul, reorganizes its anatomy. Everything loose below the composer folds into the shell itself; tools appear where the hand already is.
  • All meta lives inside the shell — hints/status/follow-up rows removed from below; ~90px of vertical space reclaimed for messages.
  • Tool row inside the composer: attach (+), quote-from-source, and a Drill menu (quiz · flashcards · outline) on the left; model chip + grounded-source chip on the right.
  • Follow-ups move above the composer as dismissible context chips — shown once after each answer, never during typing.
  • Streaming phase pill docks to the shell's top edge ("reading → thinking → answering"), replacing the loose pulsing row.

B Console Deck tool-forward
The composer becomes a small command console: settings up top, workspace below. Answers shed their card boxes and sit directly on the page like terminal output in a fine journal.
  • Three-band console: context strip (model + focus selector) → textarea → action rail (attach, quiz/flashcard shortcuts, token meter, square send).
  • Cardless answers: open typography with brass superscript citations; actions float in the left gutter on hover.
  • Jump-to-latest pill appears when you scroll up during streaming.
  • Token meter gives power users a live sense of context budget.

C Quiet Page minimal · content-first
Removes almost every box. The conversation reads like a well-set document; the composer is a single hairline that only becomes furniture when you need it. Calmest option — closest to premium reading apps.
  • No bubbles, no cards: turns separated by a faint brass rule; "YOU" set in tiny mono caps, right-aligned.
  • Citations become superscripts with dotted underlines; hover shows the quoted passage.
  • Collapsed composer: one line — placeholder + arrow. Focus expands it into the familiar lamp-lit shell (both states shown).
  • Suggestions as quiet text links, shown once per answer then gone.

D Studio Dock context-aware · command bar
A floating dock that carries its grounding with it. You always see which sources you're talking to, and slash-commands put the study generators one keystroke away. Streaming reads as a light-line across the dock's crown.
  • Context strip: toggleable source chips (✓ = grounded) live inside the dock — replaces hidden focus state.
  • Slash commands: type “/” for quiz · flashcards · outline · compare, with ghost autocomplete inline.
  • Crown progress line sweeps the dock's top edge while streaming; stop button sits beside send.
  • Answers keep cards but get a header: model badge + time + consolidated ⋯ menu — cleaner than two loose action buttons.
